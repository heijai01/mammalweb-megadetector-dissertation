# Thresholds and Trade-offs in Computer Vision

**Evaluating MegaDetector on MammalWeb Camera-Trap Images**

This repository contains supplementary materials for a Data Science Research Project completed as part of the **Master of Data Science programme at Durham University**.

The project evaluates Microsoft MegaDetector for human, animal and vehicle detection on MammalWeb camera-trap images, with a focus on confidence thresholds and the trade-off between false positives and false negatives.

## Contents

This repository may include:

- Python code used for data preparation and validation sampling
- Statistical analysis and threshold evaluation
- Code for the manual-annotation interface
- Supplementary tables and figures

## Data Availability

Raw MammalWeb images and database extracts are not included because of data-access and privacy considerations.

The repository is intended to supplement the submitted dissertation and provide additional code and analysis outputs used in the project.
